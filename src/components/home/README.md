# Homepage Sections

This directory contains modular, self-contained sections of the homepage derived from `XSW_UI.pdf`:

- `HeroSection.tsx` - Main banner with headline "A Popular Choice Among Businesses", search mockup, and hero imagery
- `SocialProofSection.tsx` - Trusted brand logos (Tata, Reliance, Infosys, Amazon, Flipkart, BYJU'S, OYO) and rating cards (Clutch 4.8, Trustpilot 4.6, Google 4.9, Upwork 4.8)
- `ServicesSection.tsx` - "Your Complete Digital Growth Partner" grid showcasing 6 core services
- `ProcessSection.tsx` - "From Idea to a Powerful Website" 4-step workflow cards
- `AboutSection.tsx` - "A Team That Turns Ideas Into Impact" with feature pillars
- `EcosystemSection.tsx` - "Powering Ideas for a Smarter Tomorrow" SaaS showcase
- `StatsSection.tsx` - Key metrics (50+ Projects, 10+ Industries, 3+ Years, 100% Satisfaction)
- `CTASection.tsx` - "Digital Experiences for a Brighter Tomorrow" conversion banner
